# Voice Samples for XTTS v2

## Requirements
- **Format**: WAV (16-bit PCM, mono)
- **Duration**: 6-30 seconds (10-15s ideal)
- **Quality**: Clear speech, minimal background noise
- **Sample rate**: Any (XTTS resamples automatically)

## Default Voices
Place default Alita voices here:
- `alita_en.wav` — English reference voice
- `alita_hi.wav` — Hindi reference voice

## Tips for Best Results
1. Record in a quiet room
2. Speak naturally at normal pace
3. Include a variety of tones (questions, statements)
4. Avoid music or sound effects
5. 10-15 seconds is the sweet spot
